\# Frontend-Dev 🚀  

A complete, organized frontend learning repository where \*\*every topic has its own branch\*\*.  

This keeps the repo clean, modular, and extremely easy to manage and learn from.



---



\# 📦 Repository Structure (Branch ↔ Folder Mapping)



Each branch contains ONLY one dedicated topic.  

Below is the exact mapping of folders and GitHub branches:



| Branch Name                  | Local Folder Name              | Description                               |

|-----------------------------|--------------------------------|-------------------------------------------|

| javascript                  | Javascript                     | JavaScript basics, DOM, functions, events |

| responsive-css              | ResponsiveCss                  | Responsive layouts, media queries         |

| intro-to-web-dev            | IntroToWebDev                  | Web development fundamentals              |

| html-iframes                | HTMLIframes                    | iFrame usage in HTML                      |

| html-block-inline-elements  | HTMLBlock\&InlineElement        | Block vs inline elements                  |

| html                        | HTML                           | HTML basics and tag practice              |

| flex                        | CSSFlexbox                     | Flexbox layouts and alignment techniques  |

| css-model                   | CSSModel                       | CSS Box Model                             |

| css-classes                 | CSSClasses                     | CSS selectors \& class-based styling       |

| css                         | CSS                            | Basic CSS concepts                        |

| bootstrap                   | Bootstrap                      | Bootstrap components, grid, utilities     |



---



\# 📁 How This Repository Works



\- \*\*Every topic = Separate branch\*\*

\- You switch to the branch of the topic you want to study

\- The branch contains only the files related to that topic

\- Cleaner learning  

\- No mixed files
